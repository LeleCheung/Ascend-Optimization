# 证据层次

先核对源码、测试合同、设备、输入与采集范围。成对 profiling 比较同一输入下候选与参考的实际设备执行。正式性能来自 KGS 完整调用计时；独立 profiling 时间和模拟器时间单列。

搬运量与指令数使用完整记录总和；流水时间、比例使用逐硬件核分布，保留均值、极值、有效与缺失数量。平均搬运粒度为总搬运字节数除以总搬运指令数。候选/参考比值为事实，不直接表示原因；两侧 program 数不同时必须同时查看采集范围。

热点指令按报告时间、cycles 排序，再扩展到源码循环或邻域。源码映射使用已有编译调试信息；实际 IR 必须与候选绑定。不同流水可能重叠，指令时间不能累加成完整耗时。时间轴中的可见空闲不等于已证明的因果空泡。

Roofline 需要同口径工作量、字节数、时间及参考吞吐。经验 microbenchmark 包络与标称物理峰值分开，接口字节与物理内存流量分开。证据不足时说明缺少什么，不用活跃比例替代峰值利用率。
