# KGS v6.5.0 发布说明

本次将本地 KG 所需的硬件中立部分从 KGS 服务端拆为同仓库的 `kernelgen-server-client` 发行包（包版本 `0.1.0`）。客户端只包含 Protocol wire models、HTTP 调用、Catalog 解析、确定性 Bundle 打包、Gems suite 静态发现及 Debug/Profile 请求模型；Bundle 存储、评测、Profiler backend、Debug 进程和设备调度仍在 KGS。旧 `kernelgen_server` 导入路径转发到同一套客户端类，避免双份 Schema。KGS release 更新为 v6.5.0，Protocol 保持 v6.2（兼容 v6.0）；客户端包版本不是协议兼容信号，运行时仍检查 `/status.api_version` 和 capabilities。

在目标 KGS checkout 中先运行 `python3 -m pip install -e ./client`，再运行 `python3 -m pip install -e '.[server]'`；受管 `kg server start` 自动按相同顺序执行。KG 本地只安装从其锁定 KGS commit 构建的客户端，不预装目标服务端。KGS exact checkout、clean 状态、受保护的 Torch/Triton/厂商运行时检查及远端 loopback/SSH stdio proxy 边界保持不变。直接从包索引安装完整 KGS 需要包索引同时提供 `kernelgen-server-client==0.1.0`；本次已验证的交付路径是 Gitee exact checkout 与 KG 管理安装，不声称客户端已发布到公开包索引。

功能提交 `f51ad972` 已在 NVIDIA H20 7 号卡和燧原 ZIXIAOC200 7 号卡通过配套 KG 真机验证：H20 默认 KernelGen 的测试审核 `ACCEPTED`、候选 Eval 36/36 `PASSED`、Profile `completed`、最终复验 `PASSED`；两台目标的本地 Native Bundle 上传、绑定 Preflight 和 Eval 均通过。H20 与驻留进程共用物理卡，成绩不代表独占性能。原始证据、精确 KG/KGS 开发提交及最终 geo mean 见 KG 的 [客户端拆包真机报告](https://gitee.com/BaaiAC/kernelgen/blob/dev/docs/validation/kgs_client_split_gpu_e2e_20260925.md)。发布收尾另有 **54 项相关 host 测试通过**；在全新隔离 venv 中先安装 client 再安装 KGS `[server]` 成功，两包从发布 worktree 导入同一套 Definition，client-only 阶段没有安装 KGS、Torch、Triton 或 FastAPI，完整安装后也没有安装 Torch、Triton 或厂商运行时。本次发布收尾仅变更版本元数据、断言和说明，不冒充发布 tag 自身再次运行了全量 GPU E2E。

本次不移动旧 tag，不自动升级已有实例或中途替换 campaign。发布分支为 `chore/release-kgs-v6.5.0`；最终 release PR、main commit 和 tag 的对应关系记录在 Gitee Release，配套 KG 将在 KGS 最终提交确定后更新 exact commit 锁定并单独发布。
