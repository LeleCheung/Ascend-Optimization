## 验证与发布门禁

本次发布不改变上述执行逻辑，仅补充 KG v6.2.0 的兼容清单项、版本断言和发布文档；发布门禁复跑两仓库 host 测试，结果记录在发布提交与 annotated tag。此前 H800 证据对应 KGS `965316f53765b4cb4da399e8002232f084f8d3f4` / `0e1f45bca41e9bebae7214ac31c8119e44a33329` 开发快照，保留原记录，不把旧真机结果改写为新 release commit 的实测结果。

发布门禁结果：KGS 317 passed、28 skipped，KG v6.2.0 配套源码 1019 passed。两侧均从隔离的临时 worktree 导入；KGS 使用精确、干净的 FlagGems checkout，跳过项为缺少 Torch 或未启用的设备 E2E。本次未重新运行真机实验。

KGS 四个功能快照已分别通过完整 host suite，依次为 287、288、298、317 passed，均有 28 skipped（缺少 Torch 或未启用设备 E2E）。最终 v6.3.0 快照的包版本、公开版本和兼容清单一致性已验证；没有安装依赖、启动设备服务或修改厂商运行时。KG 的配套 host 结果由 KG 提交记录维护。

功能 PR !32 已合入 main。本次发布收尾按维护者明确授权直接 fast-forward 推送 main，不另建 PR；发布提交与 v6.3.0 tag 一起推送。配套 KG 功能来自 [KG !73](https://gitee.com/BaaiAC/kernelgen/pulls/73)，合入 dev 的 commit 为 `f4c774d3a9249d177ad4821aaac639b90c6dd9d2`，随后由 KG v6.2.0 发布提交锁定本次 KGS tag 的精确 commit。
