# Archived AKG Bench Lite v5 operator catalog

This `v5.1` Catalog is not supported by the current Server. It is retained
under `data/.old/` only as migration input and historical evidence.

This directory is generated by `tools/convert_akg_bench_lite_v5.py`. The legacy source has one unphased workload per operator, so the converter emits distinct correctness and timing workload identities with the same inputs. For competition parity, every emitted workload explicitly uses `rtol=0.01` and `atol=0.01`.

Regenerate from a sibling checkout:

```bash
PYTHONPATH=. python3 tools/convert_akg_bench_lite_v5.py ../unified-trace-akg-bench-lite --output data/.old/akg-bench-lite-v5 --force
```
