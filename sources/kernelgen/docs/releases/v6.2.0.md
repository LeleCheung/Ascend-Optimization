# KG v6.2.0 发布说明

本次新增面向算子生成与优化的 `kg` CLI，复用现有 Python launcher 和 Workflow；其他 Workflow 继续使用 Python 入口。推荐组合为 KG v6.2.0 / KGS v6.3.0 / Protocol v6.2，配套验证范围为 host；精确 KGS 发布 commit 见 [锁定清单](../../deployment/kgs.lock.yaml)，KG 发布 commit 由 annotated tag v6.2.0 指定。

## 兼容与验证

KG、KGS release 与 Protocol 保持独立。运行时协议兼容只看 `/status.api_version`，可选功能只看 capabilities；Catalog 与 Server 生命周期解耦。Coder lease、KGS 请求线程、设备 slot 保持独立；取消仍在完整模型输出结束后处理，性能事实仍以 ledger 为准。没有实现 `--operator-dir` 或 Bundle 执行绑定，`evaluation_binding=false` 不变。

发布收尾仅将包版本与 kg_release 更新为 v6.2.0、锁定 KGS 正式发布 commit，并更新版本断言和文档；不改执行逻辑。发布门禁复跑完整 host suite，结果记录在提交正文与 annotated tag；测试核对两个临时 worktree 的导入路径，不安装依赖或启动设备任务。

此前 [H800 验证](../validation/kg_cli_refactor_h800_20260906.md) 已覆盖 SimpleOpt、YAML Batch、KernelGen 双 Coder、取消续跑、Ctrl+C、在途 operation 取消和 Profile；实测为报告记录的 KG v6.1.2 / KGS v6.2.4 开发快照，不是本次 release tag 的重新真机实测。实验原始目录和历史 commit 记录保持不动。

本次版本与发布文档收尾按维护者明确授权直接 fast-forward 推送 dev，不另建 PR；发布提交与 v6.2.0 tag 一起推送。发布不升级 Torch、Triton、厂商运行时或 FlagGems exact revision，不自动升级已有 campaign 或 Server 实例。
