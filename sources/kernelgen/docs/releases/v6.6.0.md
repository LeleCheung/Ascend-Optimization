## 验证边界

[A100 新 Definition 验证](../validation/gems_definition_review_a100_20260925.md)覆盖本地导出和 CLI 优化；[跨芯片复测](../validation/multiple_device_relu6_20260925.md)记录 A100 及部分国产芯片的分层 reference/候选结果。昇腾、海光、摩尔、沐曦已取得有效的 reference 和候选结果；燧原完成 reference，但候选受硬件网格限制。平头哥的 KGS 部署认证与天数访问尚未完成，按用户决定暂不作为此次发布门禁；昆仑芯等待镜像更新。这些目标不记为通过。本次发布收尾在隔离 KG/KGS 导入路径下运行版本、安装和 Server 管理相关 host 测试，**110 passed**；未重新运行全量测试或完整跨芯片 E2E，不能把旧组合的实测结果说成 v6.6.0 tag 的全平台 E2E。

发布分支 `chore/release-kg-v6.6.0` 仅更新 KG 包版本、KGS exact commit 锁定、版本测试及推荐组合文档。最终 dev commit 与 tag 的对应关系以 Gitee 发布记录为准。
