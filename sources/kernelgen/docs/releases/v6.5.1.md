# KG v6.5.1 发布说明

本次为配套数据更新的 patch 发布，不修改 KG CLI、Workflow 或运行时逻辑。将 [deployment/kgs.lock.yaml](../../deployment/kgs.lock.yaml) 中的 KGS exact commit 从 `a3112ba3fbf733fbb57d231292ce595fbec4e1a5` 更新为 `4bd6702666dc321c58544ff8a06a27aa22550604`，纳入 KGS [!59](https://gitee.com/BaaiAC/kernelgen_server/pulls/59) 的 `model-op` Native Catalog：20 个算子、552 个正确性 workload、455 个计时 workload。

配套组合为 **KG v6.5.1 / KGS v6.3.4@4bd6702666dc321c58544ff8a06a27aa22550604 / Protocol v6.2**。KGS release 和 Protocol 元数据未变化，本次只发布 KG tag `v6.5.1`，不移动任何旧 tag，也不创建或移动 KGS tag。KG exact commit 由 annotated tag 和发布 PR 记录，不在源码中自引用。

## 使用影响

新部署使用更新后的精确 KGS checkout，因此包含 `model-op` Catalog。已有命名 Server 实例、冻结 workspace 和运行中的 campaign 不自动升级；同一任务中途不得替换 KGS、framework 或 Catalog 快照。CLI 使用方式与 [v6.5.0](v6.5.0.md) 一致，目标设备与 capability 仍由 KGS 返回。

## 验证与追溯

用户已确认这批 Catalog 完成验证，并要求不重复运行算子实验。本次只检查发布版本一致性、锁定 KGS compatibility/manifest，以及相关 host 回归；不将用户确认扩大为本次重新执行了完整部署或 Workflow E2E。`validation_scope: host` 保留为本次 KG 发布检查范围。

本次 `test_version.py`、`test_install_kgs.py`、`test_cli_server.py` 和 `test_server_start_gems.py` 共 96 项通过；测试导入已隔离到发布 worktree 和锁定的 KGS `4bd67026` checkout。

发布分支为 `chore/release-kg-v6.5.1`，仅含版本锁定、包元数据、版本测试和推荐组合文档。对应 KG PR 编号、最终 dev commit 与 KGS !59 的映射由 Gitee Release 记录。使用与部署入口见 [ONBOARDING](../ONBOARDING.md)。
