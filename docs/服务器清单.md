# 服务器清单

以下为已记录的硬件信息，实际可用设备和占用以登录后的检查为准。SSH 认证信息与私钥存放于机器本地；910B 控制端配置见 [Linux 控制端迁移](Linux控制端迁移.md)。

| 主机别名 | 加速卡 / 设备 | 主机 CPU | 系统可见逻辑 CPU |
|---|---|---|---:|
| `baai-h20` | NVIDIA H20-3e ×8，每个约 140 GiB | Intel Xeon 6759P-C | 240 |
| `baai-910b` | 华为昇腾 910B4-1 ×8，每个 64 GiB | 华为鲲鹏 920，ARM64 | 192 |
| `baai-p800` | 昆仑芯 P800 OAM ×8，每个 96 GiB | 双路 AMD EPYC 9K84 | 384 |
| `baai-bw1000` | 海光 BW 系列 ×8，每个约 64 GiB | 海光 Hygon C86 | 128 |
| `baai-mc550` | 沐曦 MetaX C550 ×8，每个 64 GiB | 双路 Intel Xeon Platinum 8460Y+ | 160 |
| `baai-tianshu` | 天数智芯 BI-V150，可见 16 个设备，每个 32 GiB | 双路 Intel Xeon Gold 6330 | 112 |
| `baai-s60` | 工具报告 ZIXIAOC200 ×8 | AMD EPYC 9754 | 256 |


- **H20**：NVIDIA CUDA。
- **910B**：华为 CANN、Ascend C；主机也是 ARM 架构。
- **P800**：昆仑芯 XPU。
- **BW1000**：海光 DTK。
- **C550**：沐曦 MACA。
- **天数**：天数 COREX。
- **S60**：当前安装的是燧原相关工具和 TopsRider 环境。
