# 矩阵乘方法生成实验

CC+DeepSeek 根据固化的 FP32 双 tile 建议生成了有效候选，42/42 完整通过。最终两次相对 PyTorch 为 **0.910×、0.909×**，取较慢值 **0.909×**；本批起点为 0.871×，最终提升 **4.36%**，超过 0.8× 验收线。

实际修改：仅在连续 FP32 输入、M/N/K 均为 256 倍数时，新增 BM128、BN128、BK128 的双 N tile 路径。每次读取 A 面板后计算两个相邻输出块，两个 FP32 累加器各完成一条 dot；最后融合 bias 和 ReLU。半精度及不规则形状沿原入口回退，完整评测已覆盖原合同。代码中注释提到“两段 K 循环”，实际是单个 K 循环内执行两条 dot，以源码为准。

第一轮沿 K 方向 reshape/split，在编译阶段出现 AssertionError，未采纳；第二轮改为沿 N 方向双 tile，初测 0.915× 后采纳。初测提升不作为最终成绩，最终采用两次独立复验较慢值。

最终源码 SHA256：`7d389c27411a2dab7629b80d3fc76fb1cdc0a93d1cf5bc5fe97ee5e420bf35ff`。来源为真实模型响应，已核验两个候选源码及 16 份真机附件；原响应、失败日志、提示词、完整知识与逐 case 结果保存在本目录。

本批使用真实延迟、PipeUtilization 和源码推导修改，未建立数值 Roofline。方法收益比较本批起点与最终复验，固定历史源码复现另行记录。
