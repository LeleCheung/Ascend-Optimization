# narrow_copy 精简汇报

四版本完整通过 **33/33**。相对 PyTorch 依次为 **0.010×**、**0.495×**、**0.806×**、**1.102×**。

小连续片段走 CANN DMA，大输入采用少量 Triton program 循环复制，消除逐元素动态除法。相对固定 master 提高 **108.23×**，超过 0.8× 目标。

性能是同合同设备计时下逐 case 加速比的几何平均。完整源码、逐 case 数据与 SHA 见 [版本对比](版本对比.md)。
最终实现类型：小输入 CANN DMA + KG profiler 循环复制 Triton；设备任务计时包括 DMA 与 AIV kernel，输出重新分配并实际复制。
