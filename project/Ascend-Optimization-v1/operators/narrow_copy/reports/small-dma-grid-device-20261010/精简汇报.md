# narrow_copy 阶段汇报

固定 FlagGems master 的启动兼容基线为 **0.0103×**；我们简化连续索引、扩大分块后，纯 Triton 版达到 **0.582×**。根据 PyTorch 真机 trace 的 DMA 复制路径，对小连续片段使用 CANN DMA、大输入保留 Triton，进一步达到 **0.874×**，超过 0.8× 门槛，相对兼容基线提高 **84.37×**。

三版均完整通过 **33/33**，包括 18 个正确性和 15 个性能 case。计时是设备任务耗时，包括 DMA 与 AIV kernel；优化版属于 **CANN DMA + Triton 混合实现**。KG 无 profiler、有原生 profiler 的独立复验仍在进行，四版本完成后另行生成总表。

逐 case 数据与实际源码见 [候选对比](版本对比.md)和同名 CSV、JSON。
