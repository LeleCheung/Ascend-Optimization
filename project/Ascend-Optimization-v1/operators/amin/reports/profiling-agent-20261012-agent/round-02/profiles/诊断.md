## 证据边界

- profile 与正式 Eval 是独立采集，不能相减推断精确 host 开销
- profile evaluation_id 不是正式 Eval ID；通过 Definition 指纹、case 与完整候选源码绑定
- 未采集的 case 只保留正式计时，不推广其他 case 的瓶颈结论
