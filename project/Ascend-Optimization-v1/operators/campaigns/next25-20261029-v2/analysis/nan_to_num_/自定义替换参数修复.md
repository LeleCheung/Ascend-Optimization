## 问题与修改

当用户要求“NaN替换为Inf，原来的Inf替换为0”时，应该分别根据原始输入选择替换值。旧候选先把NaN替换成Inf，随后又把刚生成的Inf替换成0：

```python
y = tl.where(x != x, nan_v, x)
y = tl.where(y == float("inf"), pos_v, y)
y = tl.where(y == float("-inf"), neg_v, y)
```

修订后，判断始终使用原输入`x`，保留用户指定的新值：

```python
y = tl.where(x != x, nan_v, x)
y = tl.where(x == float("inf"), pos_v, y)
y = tl.where(x == float("-inf"), neg_v, y)
```

三个布局路径各修改两处比较，共六处；启动、分块和布局策略沿用CC生成版本。NPU PyTorch对照确认了修复前的六项失败，修订后这些检查全部通过。性能变化较小，本次修订的成果是补全自定义参数语义。
