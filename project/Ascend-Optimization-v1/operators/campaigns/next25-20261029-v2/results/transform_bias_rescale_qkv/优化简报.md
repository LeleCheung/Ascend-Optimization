# transform_bias_rescale_qkv：从单元素读写恢复成块搬运

QKV变换将输入拆为Q、K、V，加入bias、缩放Q，并重排为多头布局。本轮在固定FlagGems与FlagTree上发现：扁平索引写法经过后端编译后，退化为逐元素读写。改为显式二维块、简化宿主元数据，并在Q分支用FP32相加后缩放，最终v4达到 **0.92367×，完整21/21、扩展补测48/48通过**。旧v3的0.95141×因FP16缩放前溢出，仅47/48，不作为交付版本。下述硬件机制证据保留原始v2范围。

成绩为19659的完整调用计时，相对本机PyTorch，门槛为0.8×。独立代表参考路径审计已完成，状态为`npu_paths_observed`，v4已计入本批新达标；审计的代表输入范围见`reference-audits/transform_bias_rescale_qkv/result.json`，与下述FP32大输入profiling分别保留。

## 源码到实际IR

旧版从一个扁平向量反复拆解坐标，再构造各输出地址：

```python
offsets = pid * BLOCK_SIZE + tl.arange(0, BLOCK_SIZE)
head_dim_idx = offsets % head_dim
seq_idx = (offsets // head_dim) % seq_len
head_idx = (offsets // head_dim // seq_len) % num_heads
```

实际ttadapter将相关读写展开为步长1的标量循环，读取单个float，再插入向量：

```mlir
%q_val = scf.for ... step %c1 ... {
  %single = memref.reinterpret_cast ... sizes: [1], strides: [1]
  %value = memref.load %single[...] : memref<1xf32, ...>
  %updated = tensor.insert %value into ... : tensor<1024xf32>
  scf.yield {DiscreteMemAccess} %updated
} {ExtractedLoadOrStore}
```

新版将batch/head放入program维度，在单个program内显式表示二维块，并让一组bias沿序列行复用：

```python
rows = tl.program_id(0) * 64 + tl.arange(0, 64)
columns = tl.arange(0, BD)
channels = head * D + columns
input_offset = batch * XS0 + rows[:, None] * XS1 + channels[None, :] * XS2
q = tl.load(X + input_offset, mask, other=0)
qb = tl.load(BIAS + channels * BIAS_STRIDE, columns < D, other=0)
tl.store(Q + output_offset, (q + qb[None, :]) * (D ** -0.5), mask)
```

该输入的新实际IR保留`tensor<64x64xf32>`块和`tensor<64xf32>`的bias；离散访问标记、单元素memref.load和上述循环均为0。数学公式、真实input/bias stride和输出独立性保留，额外检查覆盖输入与bias分别非连续、输出互不覆盖、换数据及换stream。

这次定位到的是固定后端对这类扁平索引的具体编译结果；显式二维布局成功引导了成块读写。后续诊断可以将“离散访问IR信号＋异常高搬运指令数＋过小搬运粒度”组合为待验证方向，而不是只看一个活跃比例。
