# subtract_：原地减法优化

`subtract_`计算`A -= alpha × B`，返回原来的A，并支持B广播及非连续视图。

固定FlagGems本批仅通过27/30；HG-KDA修订版达到**相对PyTorch 1.100×、完整KGS 30/30、补测72/72**。采用本批KGS19659的完整调用计时。

主要改动是复用编译产物和启动元数据，减少每次调用的分派与参数绑定工作，并在每次调用时更新输入地址、alpha与当前stream。乘减仍在同一kernel完成；非连续及广播输入逐维使用真实stride，原地写回A，保持B不变。
