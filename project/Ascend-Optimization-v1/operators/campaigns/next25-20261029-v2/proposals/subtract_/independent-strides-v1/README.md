# subtract_：两个输入分别检查连续性

CC/DeepSeek第二轮候选完整KGS通过30/30，独立复验1.069×；新增补测通过66/72。失败的六项均为A连续、B同形状但通过切片或转置得到的非连续视图，覆盖FP16、BF16和FP32。

根因是普通回退函数只检查A的连续性与两个输入的形状，就调用平面索引kernel，漏检B的stride。该提案增加B的连续性条件，其余情况使用已有的逐维真实stride寻址；四个Triton计算函数AST保持不变。连续输入的编译产物直接启动、每次更新alpha/指针/stream的路径保留。

正式评测与新版72项补测由控制器串行执行。修复实现已经生成不代表结果已通过；实际成绩见assessment目录。
