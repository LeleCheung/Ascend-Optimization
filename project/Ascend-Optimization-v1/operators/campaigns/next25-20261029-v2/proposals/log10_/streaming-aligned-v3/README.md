# log10_：大输入循环分块候选

CC第二轮独立复验为0.706×、36/36，原42项补测通过。大输入候选36～41微秒，参考16～26微秒，仍需改进。

新候选在输入大于八轮、每轮40个原分块时，限制为最多40个program，每个program循环处理两个8192元素的小块；保留先读取两块、再计算和写回的组织。仍是一次kernel launch，改变的是program数量和program内部工作量。小输入保留原计算路径。

任意尾部使用边界mask；只有元素数整除两块大小时才去掉mask。program p处理第p、p+G、p+2G……个块，所有块只处理一次。每次调用读取当前地址和stream，非16字节对齐地址回到普通JIT的真实stride路径。

数学公式不变。完整KGS与扩展后的66项布局、stream和同shape对齐切换补测仍需执行；是否保留以真实结果为准。
