# QKV变换：编译期布局候选

算子将QKV投影结果加上bias、拆成Q/K/V并变换为多头布局，Q另乘`1/sqrt(head_dim)`。候选沿用固定FlagGems的三个计算表达式，将维度、stride和缩放参数显式标为编译期常量，使寻址可以按当前输入规格化简。

bias直接按自身stride读取，避免为了连续bias额外复制。三个输出来自一次分配的三个不重叠视图，每个输出本身保持连续；补测检查输入与bias分别非连续、转置输入、三个输出互不覆盖且不修改输入。

这是Codex准备的候选，尚不能将实现或排队计为收益。正式KGS、补测和参考执行路径均由同一持卡锁队列核验；源码、请求和结果保存于本提案assessment目录。冻结合同不变，三种dtype和原计时输入全部保留。
