# QKV变换：显式二维分块

上一版已完整21/21、补测39/39，但只有0.00445×；其中大输入候选26～62毫秒，PyTorch约0.05～0.06毫秒。维度标为编译期常量后仍不足以解决问题，继续检查设备数据组织。

新候选每个program处理一个batch/head中的64行序列和一个head_dim维度的二维块。列方向直接表示连续的通道，行方向保留真实序列stride；Q/K/V分别写入连续输出。bias直接按其stride读取。

同时复用编译产物和布局元数据，所有输入/输出指针及当前stream每次读取。五个地址均满足16字节对齐时才直接启动；否则使用普通JIT，保留编译与profiling/debug回退。每次重新分配输出，不缓存结果或张量。

此时二维分块改善实际搬运的解释仍是待验证假设。完整KGS、39项布局/独立性补测及后续实际指标决定是否保留；来源与失败版本均继续保存。
