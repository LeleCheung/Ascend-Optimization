# 本轮新证据：邻点切片与确定性

初始两个FP16 case：旧2054源码完整同步调用约0.220/0.785ms，添加本机libentry约0.185/0.779ms。仅诊断，并非正式分数。libentry版正进行独立完整门禁与正式评测。

extension.extract_slice/insert_slice替代水平gather的候选出现真实vector core exception。此后同进程执行的pair_gather_r4/r16、pair_slice_r4/r16受已损坏上下文影响，失败不证明它们独立也错误。不得反复用同进程串行测试trap后的其他kernel；后续请每个新源码单独KGS debug进程，失败后由KGS检查健康，不手动重启服务。

尚需独立检验的pair源码在knowledge/initial-variants.json中，优先pair_gather_r4，读取上下相邻输入行同时产生两个输出行；所有GM地址是一维仿射，水平方向仍使用gather。寄存器/UB代价和收益必须实测。slice候选trap原件见research/initial-upsample/。

本机extension.index_select_simd可明确将多个GM行读入UB，要求索引为一维、选取轴不是末维；extension.gather_out_to_ub支持GM到UB多维gather边界。可以和普通向量指针load比较，不等同于已验证快。TLE DSA提供tile_alloc/tile_subview/tile_copy/tile_to_tensor/insert_slice/extract_slice/tile_concat，安装版本已存在，不需要更新共享环境。

累计积分隔离诊断：默认FP16 shape=(256,8)积分已有一处六次原容差区间无交集；完整1024×128仍数百处。torch.use_deterministic_algorithms(True)使本轮5种形状的cumsum与积分全部六次逐值一致。这是官方稳定执行选项的实测，不等同于原默认验收通过。原参考、容差和正式请求不变；隔离确定性结果另立实验条件，不跨请求改变共享进程全局选项。
