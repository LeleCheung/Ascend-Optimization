# 机制变换开发批次与接口适用范围

本批 `selu_` 完成两组比较：原始证据自由生成相对同批 FlagGems＋共享布局适配为0.755×，机制诊断＋通用变换为1.457×；两者均通过21项补充检查和51项完整 KGS。逐 case 实际延迟见[同合同对照](同合同对照.md)，来源与冻结身份见 `evidence-audit.json`，158项核验通过。

`tanh_` 起点通过51/51，但四项暖态探针均未捕获JIT调用，本批 `state.json` 因此保持 `needs_attention`。没有给它生成候选，不能列为优化成功；后续单独检验 `asinh_`，未修改本批冻结方法或证据。

本批缓存的是编译对象与提交参数模板，每次重新绑定当前输入和stream；数学内核保持不变。它从固定 FlagGems 数学源码＋共享布局适配起跑，不替换历史SELU最佳版，也不代表超过PyTorch。

完整方法、失败记录、独立检验与复现命令见[机制闭环报告](../../机制闭环原型-20261026.md)。
