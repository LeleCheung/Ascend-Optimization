msopprof (MindStudio Profiler For Operator) is part of MindStudio Operator-dev Tools.
Used for Ascend C operator profiling by running on the board.

Options:
   --help / -h                          <Optional> Help message.
   --config                             <Optional> Json file for op config path
   --application                        <Optional> Executable file path
   --output                             <Optional> Output path
   --aic-metrics=ability1,ability2,...  <Optional> Enable collection capability of ArithmeticUtilization / MemoryUB / Memory / MemoryL0 / L2Cache / PipeUtilization
                                                   / ResourceConflictRatio / BasicInfo / Roofline / Occupancy / TimelineDetail / KernelScale / Source / MemoryDetail / Default. 
   --kernel-name                        <Optional> Specify the kernel name to profile. It's not effective in config mode.
   --launch-count                       <Optional> Number of kernel that can be collected, number in [1, 5000].
   --launch-skip-before-match           <Optional> Set the number of kernel launch that you want to skip before 
                                                   starting to analyze the kernel, number in [0, 1000]. 
   --replay-mode                        <Optional> Data collection replay Mode, select application / kernel / range, the default value is kernel.
   --kill                               <Optional> Kill op process when the number of kernel reaches launch-count,
                                                   select on / off, the default value is off.
   --mstx                               <Optional> Enable mstx api or not, select on / off, the default value is off.
   --mstx-include                       <Optional> Specify the mstx range for msprof op to be collected.
   --warm-up                            <Optional> Set the number of warm up times. The default value is 5, range in [0, 500].
   --dump                               <Optional> Enable or disable dump flushed to disk mode, only effective when --aic-metrics=TimelineDetail
   --core-id                            <Optional> Specify the id of cores to be parsed, only effective when --aic-metrics=TimelineDetail and only effective in simulation products.
