## 实际执行与自动化范围

新采集512／1024 FP16的起点与PyTorch组件对照、同shape候选、两侧模拟器热点。Agent真实调用三次：选证据工具、选优化动作、回看实验预测。工具返回与provider请求均保留，使用历史知识明确登记。

初次真机采集及模拟器调试先独立执行；随后统一控制器恢复采用原件，自动搜索两配置、冻结选版、补充门禁、完整KGS、重新采集候选及指令。收尾追加预测复核与演示生成，原控制器结束状态另存workflow-before-feedback.json。method-executed是主队列结束时方法快照；早期失败尝试的实际命令／独立驱动见各采集目录，不将该快照声称为所有阶段的首次冻结源码。method-final另存最终复现代码和依赖，不覆盖前者。

## 证据与限制

GM／L2／L1总量基本不变，UB读写约0.831×，AIV MTE2指令数0.818×，平均搬运粒度1.217×。静态bcmlir的copy／alloc由5处降为4处。原模型“所有层次字节不变”“两配置都正式通过”等表述在核验版报告更正。

起点1087条指令／983条有源码位置，候选926条／862条有源码位置。模拟器导出后子进程退出139，两侧均为部分证据，不当作完整成功、真机时间或精确关键路径。首次两次环境失败原件保留。

transfers记录下载原件SHA、Linux别名链接及排除的compiler-cache。缓存仍保留910B；原始指令CSV／trace、源码／IR、完整评测和模型回执均同步。evidence-audit-final.json和remote-evidence-audit.json是独立核验；sync-verification.json记录两端逐文件SHA；remote-closure-check.json记录卡锁与共享服务状态。
