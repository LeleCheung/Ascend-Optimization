# 上采样原版门禁：不止1×1编译失败

本批原版独立门禁27/48通过。正式正确性中的6个1×1输出编译失败；补充检查中三种dtype的输出1×1均编译失败，stride2输入在输出1×13、11×1、17×19均严重数值错误。后者不是容差问题。

源码原因：原kernel按连续NCHW计算base_offset、h*IW+w，未传入input.stride；stride2输入的实际行距和列距不符合该假设。请一维扁平输出映射时以真实sN/sC/sH/sW读取，连续输入可保留简单寻址分支；输出保持新分配。N/C应并行分配而不是每个program串行循环全部通道。1×1输出避免二维broadcast退化，store前明确转为output元素类型，去除runtime零分母。保持align_corners、显式scales、低精度数值语义。

这些是Codex根据本批真实失败与源码给出的诊断；尚未得到修复版设备证明。详细原始错误见results/upsample_bilinear2d/parent/remaining-semantics.json。
