# 机制诊断原型：启动路径与设备分块

第一阶段目标是自动区分“调用分派成本”和“设备任务组织低效”，并检验预测。此目录是新研究模块，不回改历史实验。

开发对象使用固定 FlagGems 的 `selu_`；独立检验使用未参与本轮规则开发的 `sigmoid_`。独立指本轮方法冻结后的算子检验，不声称该数学函数未被模型预训练见过。新合同覆盖 dtype、空输入、非连续布局、奇数长度、特殊值、偏移和 stream；完整评测继续使用 KGS。

原型只建立有证据支持的调用—JIT 分派—设备提交—完成关系。设备指令依赖尚未重建，不把这个调用图称作完整微架构执行图。通过同输入、同编译产物的直接提交探针检查分派开销，再检查分块变换；探针数值不冒充正式 KGS 成绩。

冻结后的比较使用同一个代码模型、起点、候选次数、合同和探针数据；对照提供原始结构化测量，方法组额外提供执行关系、竞争假设和预测。它检验诊断表达的增量，不标为 KG 原生独立结果。成本与失败逐项记录，不能以相同候选数宣称等总墙钟预算。

本阶段计划与真实产物放在 `operators/campaigns/mechanism-pilot-20261026/`。模型源码不手工改写为成功结果；解析失败允许一次仅格式修复，语义失败保留。方法冻结后新增改动另列版本，不覆盖原独立检验。
