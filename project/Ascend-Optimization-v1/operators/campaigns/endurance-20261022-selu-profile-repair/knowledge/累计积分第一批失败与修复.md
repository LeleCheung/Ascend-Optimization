机制：PyTorch低精度参考先用输入dtype执行相邻和，再以输入dtype执行dx/2缩放，最后FP32累计并转回输出dtype。当前vector/column分支直接扩FP32相加，dot分支也只有缩放之后的cast，少了相邻和的舍入。请显式保留两次舍入，防止编译器把相邻和和缩放收缩成无中间舍入的表达式：

```python
dt: tl.constexpr = y_ptr.dtype.element_ty
a = tl.load(...).to(tl.float32)
b = tl.load(...).to(tl.float32)
pair = (a + b).to(dt).to(tl.float32)
increment = (pair * SCALE).to(dt).to(tl.float32)
# vector/column对increment做FP32扫描；dot将已舍入increment按需要转回dt后计算，保留FP32累加和carry。
```
