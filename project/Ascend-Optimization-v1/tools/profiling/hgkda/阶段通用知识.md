# 下一阶段通用约束

固定 FlagGems 提交 d6a8eec473517a3d68157b208eb9c057eb1d4c50，FlagTree 0.6.0+ascend.gitc286cba6，Triton 3.5.1、CANN 9.0.0。同批不更新编译器或测试合同。

按算子类型和实际指标选择诊断方向；搬运、Vector、Scalar 可重叠，活跃比例不是峰值利用率。复杂依赖需要指令、同步与热点证据，缺失时注明未决问题。

原地操作保留输入存储、返回别名、非连续 stride、dtype 和特殊值语义。性能计时中的重复调用及输入恢复以 KGS 固定合同为准，不能改变评测来提高成绩。涉及边界掩码的改法需要一般性整除证明、非整除回退和专家评审。

不得调用目标算子的 PyTorch 或 FlagGems 计算作为优化候选；允许元数据操作、分配和返回必要别名。若原始基线本身调用 PyTorch，单独报告，不能把基线的行为套到新候选。CANN DMA 需要单独审查真实调用链和设备任务，TLE Raw 不等同于宿主运行时异步复制。

每次 grid 维度在1到65535之间。大输入用有界网格与循环完整覆盖，不按 CUDA warp 规则假设 Ascend 映射。编译器拒绝的配置保留原始错误，不更新共享环境来掩盖失败。

性能成果必须完整正确性通过；精度修复、接口适配与性能增益分别说明。保留源码、SHA、逐 case 结果、模型输入输出和两次最终复验。
