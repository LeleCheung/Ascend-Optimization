# 四算子复现与建议驱动优化

统一入口为`run-four-operator-workflow.sh`与`four_operator_workflow.py`，配置为`four-operators.json`，知识为`工作流通用知识.md`和各算子的`优化知识.md`。仍为Markdown知识加脚本控制器，优化模式调用CC+DeepSeek，未封装成标准skill。

## 第一步：最佳源码复现

910B宿主机执行，批次名每次新测量须更换：

```bash
p=/data/hanle/ascend-optimization/Ascend-Optimization/project/Ascend-Optimization-v1
tmux new-session -d -s profiling-four-example "bash $p/tools/profiling/run-four-operator-workflow.sh example all 3 > /data/hanle/ascend-optimization/runs/four-example.log 2>&1"
```

`all`先串行复现四个最佳源码，再串行运行四个建议驱动优化；改为`replay`只复现，改为`method`只验证建议。第三个参数为每算子最多生成轮数，默认3，允许1—6；每轮生成20分钟超时，完整评测30分钟超时。

建议驱动阶段使用`--provider-thinking disabled`：CC仍调用DeepSeek，由本机临时转发器显式向供应商发送`thinking: disabled`。转发器只监听loopback，凭据只在内存转发；审计文件仅包含路由、模型、思考模式、请求摘要和HTTP状态。它随该次模型调用结束，不改全局Claude设置。

2026-10-14旧生成批次出现思考续写和分段JSON错误，已在两套KGS均空闲时停止，原状态、响应、失败候选和`interruption.json`保留。四个最佳复现仍使用`20261014-four`；接口修复后的新方法批次为`20261014-four-direct`。宿主启动命令为：

第四个参数指定已完成复现批次，只汇总这些结果，不再次执行设备复验。请求适配及原问题见[DeepSeek生成接口修复](DeepSeek生成接口修复-20261014.md)。

最佳复现固定已验证源码，完整测试、采集两个慢case、保存诊断和提示词，最后同源码两次完整复验，不调用模型。

## 第二步：验证建议

| 算子 | 优化前起点 | 固化的有效建议 |
| --- | --- | --- |
| logaddexp2 | 固定master | 稳定公式、精度安排、连续快路径、去mask、多tile与规模分流 |
| amin | 历史v5 | 整除去mask、输入精度归约尝试与FP32回退、多缓冲 |
| matmul_bias_activation | 历史v9 | FP32双N tile复用A、BK128；半精度BK256 |
| narrow_copy | 历史KG有profiler纯Triton版 | 小输入真实CANN DMA，大输入保留Triton |

这里验证明确的后续优化建议，不声称其余三个都从master重新发现全部优化。不给模型完整最佳源码，由模型在起点上执行方法；保存原响应、生成源码、失败原因和采纳记录。超过当前最佳0.5%才采纳，最终两次复验再次决定方法是否有效。

## 第三步：查看与恢复

产物位于`operators/<算子>/reports/profiling-agent-<批次>-replay/`和`profiling-agent-<批次>-method/`。汇总为`operators/四算子闭环-<批次>.md`与JSON，明确分开两种模式。每算子的日志位于reports下`workflow-<批次>-<模式>.log`。

同批次再次执行会恢复已完成步骤；已经发出但结果未知的设备请求不会自动重发。运行中不得修改知识、源码或commit/pull。宿主入口持有物理卡7锁，每次设备请求检查两套KGS空闲，不改镜像、服务或他人进程。

## 第四步：核验和交付

复现与生成各自进行完整正确性评测和两次最终复验。narrow_copy自动选择19657与device_task，包含DMA和kernel；其余使用19655与device_kernel。采用性能case几何平均，两次最终结果较慢值。

下载完整证据后可离线汇总，不连接设备或模型：

```bash
python tools/profiling/four_operator_workflow.py --batch example --report-only
```

修复后批次与之前复现一并汇总：

```bash
python tools/profiling/four_operator_workflow.py --batch 20261014-four-direct --replay-batch 20261014-four --report-only
```
