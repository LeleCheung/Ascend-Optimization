# CANNBench Official Tasks 2.0.0

This directory preserves the `data/` tree from the official CANNBench reference package downloaded from <https://cannbench.com/benchmarks>.

- Collection: `official-tasks`
- Version shown by the CANNBench website: `2.0.0 Beta`
- Website metadata: 5 levels, 60 operators, 1,200 cases
- Snapshot scope: task specifications, golden implementations, and case definitions under `data/level*/`
- Local source before copying: `0_HGKDA_docs/BAAI-reports/05_work/official-tasks-reference/official-tasks/data/`
- Use: development-time benchmark inspection and reproducible task selection; this data is not a runtime dependency of HG-KDA.

The task files were copied without edits. The downloaded reference package did not include a separate license file. Preserve this source attribution and verify the upstream redistribution terms before publishing this snapshot in a public release.
