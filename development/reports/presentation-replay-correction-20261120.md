# IR修改继续模拟器重放

用户纠正后，统一表达为：**继续模拟器重放当前版本 → 定位热点、流水空泡与等待 → 关联源码及实际IR → 选择Triton／IR修改层 → 编译修改版并再次重放 → 结合完整真机验收保留最佳 → 下一轮重放**。

模拟器重放贯穿优化迭代，Triton／单算子IR／通用pass描述修改位置。模拟器执行实际编译产物，绑定case、真实输入、源码／IR与二进制SHA。用户随后确认IR方法文字及箭头统一采用橙色模拟器指导、绿色三角形表示IR层；设备kernel／host／both继续采用圆／方／菱形。模型、profiling、模拟器和Codex的各项贡献依原证据分别记录。

既有三项案例的实际顺序为：读取修改前重放证据，模型登记并修改IR，编译及完整真机评测，随后采集修改后profiling与模拟器重放。流程图概括各环节，原日志保留执行先后。
