# 根据模拟器信息选择IR修改

当模拟器显示**生成代码中存在有成本的热点、重复工作或流水等待**，并且实际IR与低层产物能定位其形成方式，就可以评估单算子IR修改。选择前要形成一条可检验的机制链：执行观察 → 对应IR → 局部变换 → 预期指令／流水变化 → 真机收益。

| 模拟器观察 | 关联IR后检查什么 | 可以评估的IR方向 |
| --- | --- | --- |
| 向量流水有效工作占比高，选择／转换／搬移为热点 | 宽位操作是否可在窄类型上等价执行，布局转换是否仍进入最终产物 | 选择前移、窄类型传播、消除重复转换及切片 |
| gather、比较和select在固定循环中反复执行 | 迭代状态是否已收敛，索引是否均匀，尾步是否仍产生信息 | 删除冗余尾步、均匀性传播、简化固定迭代 |
| 相同向量整数每轮统一加一，转换指令读取同一缓冲 | 全部lane是否保持相同，掩码、零迭代、溢出及最终转换是否等价 | 标量循环携带、末端广播；同时测量新增标量与同步成本 |
| 每个tile重复BAR／WAIT，搬运与计算交替形成空泡 | 等待对应的数据依赖、tile轮次、buffer生命周期及UB容量 | 调整局部分块、搬运组织、流水调度及合法同步位置 |
| 标量指令热点，向量或搬运流水等待标量 | 地址计算和循环不变量是否在最终低层仍反复执行 | 纯计算外提、地址及索引简化；检查低层指令是否实际减少 |
| 源码中的并行原语在模拟器表现为串行执行 | 实际lowering是否形成逐元素循环，目标路径是否可向量化 | 检验单算子lowering改法；记录数值顺序及边界约束 |

选择IR前核对五项条件：

1. **证据绑定当前最佳。** 固定shape、输入、源码、IR、二进制和编译配置；后续kernel用真实中间输入隔离重放。
2. **执行成本可定位。** 热点及流水联合判断；等待高时继续区分搬运、数据依赖和同步。重叠的指令累计时间分别解释，部分窗口保留范围。
3. **问题在实际产物中保留。** 同时检查TTIR和BCMLIR／二进制。源码中看见重复表达后，还要确认后端生成了重复工作。
4. **IR层有明确作用。** 已有算法和源码保持固定，直接检验编译阶段遗漏的变换，或精确控制当前源码难以稳定产生的执行组织。算法、网格或分块意图需要重设计时优先交给模型修改Triton。
5. **等价性和收益可验证。** 说明浮点顺序、特殊值、边界、别名、同步和资源条件；提前登记预计减少的指令、等待或轮次。修改后重新编译并重放，以固定完整KGS及既有补测验收；收益接近测量波动、重复结果矛盾或设备状态异常时再用交错复测排疑。逐项核对原预测与实际计数、时序和资源变化；性能收益和机制判断分别保存，预测偏差保留并用于下一轮选层。

相对时间轴与时钟核验各有明确含义：fraction／`relative_only`说明图按窗口归一化；绝对单位资格读取独立的`absolute_unit_validation`。核验通过的trace也可采用相对图展示。比较动态指令总数时同时核对程序结束事件与窗口覆盖量，逐PC源码对应另据实际映射材料确认。

CPU编译阶段先比较原／改最终二进制。BatchNorm广播外提使BCMLIR输出内层fill3→0，最终二进制仍逐字节一致；该候选保存为编译阶段探索，随后依据最终指令继续换假设。tensor层的outs名称、缓冲化后的物理地址与真实依赖分别核对。相关证据见[广播外提结果](midday-whitebox-20261120/batchnorm-ir004-cpu-noop.md)。

随后BatchNorm按64次S32向量计数更新研究均匀性传播。计数标量化使最终二进制8416→8264字节，完整27/27、双方各36/36通过，目标39.458→40.025μs，保持原IR。修改后正式二进制重放确认S32 VADDS64→0、向量转换2→0，30/30个PC时钟核对通过；独立profiling向量时间减少，部分等待与MTE3时间上升。该结果把“变换合法、机器码改变、真实收益”分成三个独立验收事实，见[计数标量化记录](midday-whitebox-20261120/batchnorm-ir005-case.md)。

已有案例：上采样将六个边界选择移至FP16→FP32扩展之前，固定shape耗时下降3.21%；scatter折叠二分尾步，generic gather14→13，下降1.50%；BatchNorm仅加宽输出IR，8×128→8×256，下降8.60%。各例的模拟器观察、低层机制、Codex分析及模型实现贡献分别保留于[案例入口](ir-performance-20261119/README.md)。

午间沿当前最佳继续重放后，上采样删除无效lane填充值，实际低层fill3→1、切片7→3，固定shape再降7.99%；scatter利用前两轮二分索引的均匀性，generic gather13→11，固定shape再降1.59%。两例完整合同、补测、ABBA与修改后双分析均通过。scatter新增标量读取的成本与净收益一起保存；上采样PAD指令仍存在，模型关于PAD消失的预测单列为偏差。这些案例支持逐项核对“改了什么、实际生成什么、执行变化是什么、最终快多少”，详见[午间证据入口](midday-whitebox-20261120/README.md)。

QKV的循环不变量外提和128×64直线分块通过完整数值合同，但耗时63.038／63.666μs，继续保留62.861μs原IR。这说明选层依据还要经过真实设备性能验证；变换形式更简洁时，资源占用、流水重叠和调用耗时仍须实测。

午间QKV将低层写出顺序由QKV改为KVQ，完整21/21、双方各48/48通过，目标63.258→63.652μs，继续保留原IR。修改后正式二进制重放24/24个PC时钟核对通过；独立profiling中MTE2每程序时间下降，MTE3和Scalar时间增加、AIV时间3.072685→3.126787μs。该例展示了局部流水改善与整体开销之间的取舍，详见[完整合格负结果](midday-whitebox-20261120/qkv-ir001-negative.md)。

QKV随后沿保留版的热点、流水及低层产物，将两次64×64读取改为32×128相邻双头读取，经reshape／transpose逐头写回。完整21/21、双方各48/48、ABBA及后双分析通过，历史62.837→62.050μs，固定shape下降1.25%；全合同共同参考下相对历史基本持平。后重放26/26个PC时钟匹配，MTE2／MTE3时间下降，向量时间、bias读取及写命令增加。这类布局机会适合先用固定源码IR实验隔离成本，再评估向源码或通用pass迁移，见[双头布局案例](midday-whitebox-20261120/qkv-ir002-case.md)。

BatchNorm更宽的8×1024输出IR虽完整合格、正式33.540μs，ABBA原版36.487／36.537、候选36.429／36.886μs未满足稳定性条件，继续保留8×256。后重放确认输出搬运32→8，同时每程序读取268→292KiB，预先登记的末轮重复预取增量兑现。该成本给出下一轮尾步剥离／排空方向；性能波动原因仍需独立证据。语义、低层变换、机制变化、正式计时和稳定性分别保存，见[8×1024探索及续接](midday-whitebox-20261120/batchnorm-ir006-case.md)。

随后保留分块的尾步剥离通过完整27/27、双方36/36，后重放确认读取268→256KiB／程序，但向量BAR仍484次，目标39.397766μs慢于历史39.261332μs，继续保留原IR。模拟器指出的重复工作可以作为局部变换入口，净收益还取决于仍保留的算术、同步与新增尾步成本；下一轮根据该反馈检验统计分块。时钟35/36个PC匹配及剩余MOV_SPR_XN局部偏差一起保存，见[末轮预取案例](midday-whitebox-20261120/batchnorm-ir009-case.md)。

统计分块8×256把目标递推32→16轮，后重放显示BAR484→330、DIV82→58，正式目标36.136μs，完整27/27及既有双方36/36通过。由于归约分组改变，修改前预登记的25项数值诊断进一步发现空间维256、偏移128输入有新增超差，继续保留39.261μs。性能机制有效与数值修复分开记录，模型沿显式未保留探索分支研究稳定的中心化表达。该例说明归约IR变换需要检查舍入、消减及下游使用方式，见[统计分块及数值边界](midday-whitebox-20261120/batchnorm-ir010-case.md)。

随后模型以通道首元素作为公共原点、使用残差均值完成ir-011修复，固定Triton源码，目标39.261→37.200μs，下降5.25%；27/27及既有双方36/36通过。复用相同25项诊断，原版19项通过、新版23项通过，新增回归0，剩余两项继承的窄分支精度边界单列。后重放BAR484→304、DIV82→50；修复增加的标量和向量加法成本与净收益一起保存。该轮按条件策略跳过ABBA，详见[公共原点与残差均值案例](midday-whitebox-20261120/batchnorm-ir011-case.md)。模拟器揭示成本后，归约类IR机会还应结合实际浮点表达和固定精度验证选择；一次性风险诊断冻结复用。

日常迭代复用固定合同和既有补测。遇到具体语义风险时，一次性登记针对性诊断及同输入原／改比较，后续修复复用该集合；继承的基线精度边界与候选新增回归分别记录。源码、IR和产物由工具自动关联，日常沟通聚焦改法、机制和真实性能。所有trace图隐藏同实现复测，原始测量保存在详情。

多个算子反复出现相同编译缺陷后再评估通用pass，并建立适用条件与回归集合。目标硬件操作需要新增语言或后端表达能力时，进入独立的custom op／Ascend C研究线。各条路线继续使用模拟器重放闭环。

选层说明还要区分语言表达能力与实验条件。Triton能稳定表达优化意图时优先修改源码；固定源码的IR实验用于隔离编译变换、研究自动优化机会。报告写清这一选择和源码可替代写法，表达能力判断依据已安装语言与后端支持。

11月20日夜间新增两个固定源码IR例子。GroupNorm的原IR跨统计和归一化分两遍读取输入；profiling每program读取256KiB，模型据实际IR、热点和流水改为保留首遍8通道值，后端动态输入copy16→8，设备读取降到128KiB。目标24.812→23.734μs，下降4.34%，全合同耗时几何平均下降0.085%。后窗口和指标同时显示Scalar等待增加。该机会可用Triton的值生命周期重组表达；本例按固定源码实验隔离复用变换及资源代价。

回填原IR构造整行广播、比较与select，模型改为先写零行再覆盖有效单点；完整合同96/96、双方96/96和条件交错通过，目标187.771→183.792μs，下降2.12%。后profiling中Vector服务6.866→0.325μs/program，MTE3指令17→33与点写成本增加；后模拟器窗口MTE3 productive约96.73%。全合同耗时几何平均上升0.26%。模型继续研究批量连续写入，沿新反馈判断边界。该变换也有Triton可替代表达；固定源码IR实验用于检验具体lowering成本，通用pass仍需跨实例适用性研究。两例部分窗口、时钟局部差异、实际修复父链和完整材料见[新增IR案例](night-whitebox-gqa-20261120/README.md)。
