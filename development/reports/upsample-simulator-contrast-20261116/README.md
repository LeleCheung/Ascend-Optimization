日期：2026-11-16。原始同预算试点的结果是：**成对 profiling＋实际 IR 路线产生了有效改进；增加模拟器证据的一侧选择了另一种改法，但未通过编译预检。尚未获得模拟器带来净收益的合格正例。** 后续修复线单列，不作为原始同预算比较中的胜出结果。

## 固定设置

算子为 `upsample_bilinear2d`；目标 case 是 FP16 `[4,32,128,128] → [4,32,256,256]`，`align_corners=False`。共享交付起点 SHA 为 `e46260c2c74a…`。两臂采用相同模型、提示词、方法快照、源码、合同和知识；只有一侧增加单核模拟器热点、区域和时间轴。专项知识检索为空，未测试知识库的独立贡献。

每臂最多两次模型调用、两份正式新源码和四份预检；本轮均使用两次模型调用、一次实际设备优化。第二次调用用于相同的启动接口修复。共享基线的修复准备成本另计。提示词、方法与设置的哈希一致性见[原始对照清单](../../experiments/whitebox-pilot-20261116/contrast/contrast-manifest.json)。这是单任务、每臂一条路径的小规模试点，不提供统计上的独立因果结论。

共享起点在当前 profiler 路径下向 launcher 传入整数地址，引发 `Tensor.size()` 错误，原次评测为 18/24、无有效性能。CC／DeepSeek 将指针参数改为本次调用的张量对象；共享基线与两臂使用相同修复，设备 kernel 字节不因该修复改变。修复后的基线重新完整评测，启动修复不计为模拟器收益。没有放宽测试合同或改变 KGS 计时模式。

## 原始对照结果

| 路线 | 完整 KGS 合同 | PyTorch／CANN 补测 | 目标延迟 | 目标相对 CANN | 六项性能的几何平均加速比 |
| --- | --- | --- | ---: | ---: | ---: |
| 共享修复基线 | 24/24 | 各30/30 | 268.994 μs | 0.914449× | 1.395880× |
| 成对 profiling＋IR：替换 gather | 24/24 | 各30/30 | 220.026 μs | 1.117167× | 1.498919× |
| 增加模拟器：奇偶列分别写回 | 编译预检失败，未提交KGS | 未完成 | 无有效值 | 无有效值 | 无有效值 |

24项合同含18项正确性与6项性能任务。默认每份有效源码一次完整 KGS 评测；以上不是从重复测量中挑出的最好一次。当前参考为固定 CANN 原生 API 的布局兼容路径，实际包含 Cast、TransData 与 ResizeBilinear 共5个任务；参考采集完整保留全部任务，未把逐任务时间相加冒充完整调用延迟。历史汇报和本轮环境分开，不以新数值覆盖旧成绩。

成对 profiling＋IR 路线将目标延迟降低约 **18.2%**，相对共享起点加速 **1.223×**。重新采集的设备任务耗时由 268.945 μs 降到 220.324 μs，与 KGS 变化一致。

| 重新采集的候选指标 | 共享基线 | 替换 gather 后 |
| --- | ---: | ---: |
| Vector 活跃比例均值 | 0.844747 | 0.811229 |
| Vector misc 活跃比例均值 | 0.796635 | 0.756469 |
| MTE2 活跃比例均值 | 0.040041 | 0.122740 |
| GM→UB 记账搬运量（工具KB） | 8255.875 | 24640.000 |
| MTE2 指令数总和 | 8043 | 16255 |

改法用更多连续读取替换片上 `gather`，利用原先较空闲的搬入流水。GM→UB 记账搬运量增加约2.98倍，实际延迟仍下降；因此不能仅凭总搬运量判断方案优劣。这项计数可能包含 L2 命中，不能直接称为 HBM 字节数。各流水活跃比例也不直接等于关键路径耗时。

## 模拟器侧的判断与失败

修改前记录显示，无模拟器侧认为 `gather` 是主要候选；有模拟器侧查看了 `join` 附近映射的 BAR／WAIT_FLAG 热点，选择将交织改为四次奇偶列分别写回。它也记录了其他解释和所需后续验证，但这些同步指令的累计时间本身不能证明 `join` 是独立瓶颈。

四次步长写回的源码未通过完整预检，编译器报告需要 **512 KiB UB**、可用 **192 KiB**。没有为该候选报告有效性能。

单列后续线尝试按 dtype／形状限制分块，并保留原有 Triton 打包写回分支。第一次生成触及 turn 上限，接口尚未完整；两次接口续写均保存记录，其中一次没有改变源码。最终完成参数传递与缓存启动 ABI 后，设备预检触发 **Vector Core 异常（507035）**，仍未形成有效候选。这条线共三次模型调用、一次新源码设备预检，没有有效 KGS 或后续模拟器测量。编译／执行失败没有换算成零分或隐藏。

本轮数据支持成对 profiling＋IR 的改法有效；模拟器新增证据改变了模型选择，收益仍未得到验证。后续因果判断需要区域周围的依赖、编译后搬运组织与资源约束，不能只依靠热点指令的排序。
