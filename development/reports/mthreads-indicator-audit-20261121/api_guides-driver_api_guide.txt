 MUSA Driver API 提供底层编程接口，用于显式上下文管理、模块加载、高级设备控制。 
 
 设计特点 ：显式控制（需要显式初始化和创建上下文）、灵活性高（可以精细控制设备资源） 
 适用场景 ：多 GPU 应用、多进程应用、库开发、需要精细控制的高级应用
