Moore Perf Tools Moore Perf Compute 版本说明 v1.2 版本说明 本页总览 Moore Perf Compute v1.2 版本说明 
 1. 环境要求 ​ 
 OS CPU GPU Driver BIOS Ubuntu 22.04 kernel 5.15.0-15-generic（采集与回放均支持） x86_64 MT S5000、MT S4000 musa sdk 5.1.0 ≥ 4.2.7 AIBook / AIModule（采集与回放均支持） aarch64 M1000 GPU M1000 1.4.0 — Windows 10（回放或远程采集） x86_64 — — — 
 2. 概述 ​ 
 
 支持  Green Context Profiling 。
 
 
 3. 变更说明 ​ 
 3.1 新增功能 ​ 
 通用 ​ 
 
 支持 Green Context Profiling。 
 新增  Launch Statistics  Section。 
 新增离线用户手册。 
 
 GUI ​ 
 
 报告  Session  页面新增  Green Context Resources ，汇总各 Context 下 MPX 使用情况；点击  Result ID  可跳转到  Details  页面对应 kernel。 
 报告  Details  页面新增属性按钮，用于快速识别是否为 Green Context kernel；点击属性图标可跳转至  Launch Statistics  Section。 
 报告  Details  页面新增  Launch Statistics  section 指标展示。 
 Profile  配置  Filter  页面新增  Devices  配置项。 
 Help  菜单新增  Documentation ；点击 可打开离线用户手册。 
 
 3.2 限制说明 ​ 
 
 当前默认抓取所有 section 指标，暂无法通过 GUI 与 CLI 修改或取消。 
 不支持 MUSA Graph。 
 
 3.3 问题修复 ​ 
 
 修复 M1000 NPU 驱动缺失场景下分析失败的问题。 
 
 3.4 已知问题 ​ 
 
 对于实现中使用了  blockIdx  变量的 kernel， Static Shared Memory Per Block  指标会比实际设置多出  12 byte/block （为 Linux Driver 预留）。
