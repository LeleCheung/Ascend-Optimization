1. 问题与结果：26项作为背景；四算子的geomean汇成一页，明确完整合同和单shape口径。
2. 方法：profiling发现差距；有机制歧义时模拟器定位热点与流水等待；源码／IR把现象对应到改法。分析工具与修改层分别表达。
3. 四算子案例：固定shape曲线展示源码优化到IR收益的连续主线。重点讲透BatchNorm和scatter两例，其余作为覆盖不同机制的补充；完整八图保留备用。
4. IR选层：用实际“固定Triton源码、只改IR”的前后产物与真机收益说明进入IR的条件。性能达到某个CANN比值仅作为进度指标；生成代码存在具体问题才决定改层。
5. GQA研究：展示仍在推进的Triton优化，具体区分profiling足以提出的方向、模拟器新增判断、宿主历史知识与后重放核验。实际实现的层次据实标注。
6. 结论与后续：以可复查案例说明方法；单算子IR、通用pass、custom op／Ascend C按已验证工作与后续路线分别陈述。
